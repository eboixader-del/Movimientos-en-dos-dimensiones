# Movimientos en dos dimensiones · Vectoria

App educativa en español para explorar y practicar la composición de movimientos.

## Contenido

- Cruce de un río: MRU en ambos ejes, con velocidades de −6 a +6 m/s para corriente y bote. Cuando vy es negativa, el bote parte de la orilla superior. Con vy = 0 se observan 10 segundos de deriva sin cruce.
- Tiro horizontal y tiro parabólico, sin resistencia del aire y con g = 9,8 m/s².
- Escenarios ilustrados, vectores, proyecciones, ecuaciones con sustitución numérica y cuatro gráficas sincronizadas.
- Controles de parámetros, pausa, cámara lenta y avance de 0,1 s.
- Nueve misiones narrativas con pistas, comprobación de resultados y preguntas conceptuales.
- Informe individual descargable en PDF con propuestas, razonamientos, intentos y pistas consultadas.

## Uso

Descarga `index.html` y ábrelo en un navegador moderno. No requiere instalaciones, claves API ni servicios externos. Introduce un nombre o alias y comienza en «Explora».

El progreso se guarda solo en el navegador y dispositivo usados. «Nueva sesión» borra ese progreso. No se envían informes automáticamente al docente. El razonamiento escrito se incluye para revisión docente; no se evalúa automáticamente. El PDF recoge evidencias de la sesión y no certifica autoría ni dominio definitivo.

## Publicar con GitHub Pages

1. Abre **Settings → Pages** del repositorio.
2. En **Build and deployment**, selecciona **Deploy from a branch**.
3. Selecciona **main** y **/ (root)**, y pulsa **Save**.
4. Cuando termine la publicación, GitHub mostrará el enlace para compartir la app con el alumnado.

La app es autocontenida: el único archivo necesario es `index.html`. No incluye datos reales del alumnado.
